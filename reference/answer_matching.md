# Answer for a matching question

Answer for a matching question

## Usage

``` r
answer_matching(left, right, extra_choices = "")
```

## Arguments

- left:

  Character vector of the left-hand side items to be matched.

- right:

  Character vector of the right-hand side items to be matched. Must be
  the same length as `left`.

- extra_choices:

  Character vector of extra choices that can be used as incorrect
  matches. Optional.
