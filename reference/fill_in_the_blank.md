# Create a fill-in-the-blank answer for a fill-in-multiple-blanks question

Create a fill-in-the-blank answer for a fill-in-multiple-blanks question

## Usage

``` r
fill_in_the_blank(text, id = NULL)
```

## Arguments

- text:

  The correct answer text for this blank.

- id:

  The ID of the blank this answer corresponds to.
